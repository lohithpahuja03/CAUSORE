# CAUSORE Frontend

High-density engineering interface for **CAUSORE** — Evidence-driven incident investigation.

## Stack
- Next.js 14+ (App Router)
- React 18+
- TypeScript
- Clean, high-density engineering CSS / Tailwind

## Project Structure
- `app/`: Next.js pages, layouts, and route handlers.
- `components/`: Modular UI components (Timeline, Anomaly Explorer, Hypothesis Cards).
- `lib/`: API clients, utilities, formatters.
- `types/`: Strict TypeScript models.

## Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)
